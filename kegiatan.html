Kegiatan Saya

Aktivitas perkuliahan, olahraga, membaca, dan mengembangkan kreativitas.

1. Kegiatan Perkuliahan

Sebagai mahasiswa Pendidikan Teknologi Informasi, saya mengikuti kegiatan perkuliahan untuk menambah pengetahuan dan mengembangkan kemampuan di bidang teknologi informasi dan pendidikan.

Dalam perkuliahan, saya mempelajari berbagai materi seperti pemrograman, jaringan komputer, perancangan sistem, multimedia, dan teknologi pembelajaran.

2. Olahraga dan Gym

Selain kuliah, saya juga melakukan kegiatan olahraga dengan pergi ke gym. Saya berlatih untuk menjaga kebugaran tubuh, meningkatkan kekuatan, dan membangun tubuh yang lebih sehat.

Melalui kegiatan gym, saya belajar tentang kedisiplinan, konsistensi, dan pentingnya menjaga kesehatan di tengah kesibukan perkuliahan.

3. Membaca Buku

Saya memiliki kegiatan membaca buku untuk menambah wawasan dan pengetahuan. Membaca membantu saya mempelajari hal-hal baru serta meningkatkan pemahaman terhadap berbagai bidang.

Saya juga berusaha menjadikan membaca sebagai kegiatan yang bermanfaat untuk mengisi waktu luang dan mendukung proses belajar.

4. Belajar Pemrograman

Saya juga meluangkan waktu untuk belajar pemrograman secara mandiri. Saya mempelajari dasar-dasar pemrograman, HTML, CSS, Python, serta pengembangan website.

Melalui kegiatan ini, saya berusaha meningkatkan kemampuan dalam membuat program dan memahami cara kerja sebuah sistem.

5. Desain Grafis dan Fotografi

Selain teknologi, saya memiliki minat dalam desain grafis dan fotografi. Saya menggunakan Photoshop, Adobe Illustrator, dan Canva untuk membuat berbagai karya desain.

Saya juga senang mengambil foto dan mencoba mengembangkan kreativitas melalui komposisi, warna, dan pengolahan gambar.

6. Pengembangan Proyek

Saya mengembangkan kemampuan melalui pengerjaan proyek perkuliahan, seperti perancangan sistem perpustakaan digital berbasis web dan pembuatan desain antarmuka aplikasi pembelajaran.

Kegiatan proyek membantu saya memahami proses perencanaan, perancangan, dan penyelesaian masalah dalam bidang teknologi informasi.
